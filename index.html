Tổng quan

set và map là hai cấu trúc dữ liệu STL giúp lưu và tìm thông tin theo khóa. Phần dưới dùng C++17 và thứ tự tăng dần mặc định, trừ ví dụ có khai báo greater.

1. Tính chất chung và cách lựa chọn

Tính chấtset<T>map<K, V>
Thông tin lưuCác giá trị kiểu T, mỗi giá trị cũng là khóaCặp khóa kiểu K và giá trị kiểu V
Trùng lặpMỗi khóa xuất hiện tối đa một lầnMỗi khóa xuất hiện tối đa một lần, nhiều khóa có thể có cùng giá trị
Thứ tự mặc địnhTăng dần theo giá trịTăng dần theo khóa
Nhu cầu thường gặpLoại trùng, kiểm tra tồn tại, tìm giá trị lân cậnĐếm tần suất, lưu vị trí, ánh xạ tên hoặc mã sang thông tin
Thay đổi dữ liệuMuốn đổi giá trị thì xóa giá trị cũ rồi thêm giá trị mớiSửa được giá trị gắn với khóa, muốn đổi khóa thì xóa và thêm lại
  • Thứ tự được duy trì sau mỗi lần thêm hoặc xóa. Hai cấu trúc thường được cài bằng cây tìm kiếm cân bằng. Chuẩn C++ quy định hành vi và độ phức tạp, không bắt buộc một loại cây cụ thể.
  • Số phần tử có thể tăng giảm trong lúc chạy. Bộ nhớ sử dụng là O(n), với chi phí quản lý cho từng nút.
  • Tìm kiếm, thêm phần tử thông thường và xóa theo khóa mất O(log n). Đây là giới hạn theo số phép so sánh, với giả thiết chi phí so sánh khóa là hằng số.
  • Kiểu khóa phải so sánh được theo thứ tự. Khóa số nguyên, chuỗi và pair thường dùng trực tiếp. Với chuỗi, thời gian so sánh còn phụ thuộc độ dài phần tiền tố chung.

Nếu chỉ cần biết “giá trị này đã xuất hiện chưa?”, dùng set. Nếu cần biết thêm “xuất hiện mấy lần?” hoặc “ở vị trí nào?”, dùng map.

2. Set và các thao tác

Thêm phần tử và loại trùng

insert(x) và emplace(...) thêm phần tử nếu khóa chưa tồn tại. Kết quả trả về gồm iterator đến phần tử và boolean cho biết có thêm mới thành công hay không.

C++17
12345678
set<int> s = {5, 1, 5, 3}; // Contains 1, 3, 5.
s.insert(2);              // Contains 1, 2, 3, 5.
auto [it, inserted] = s.insert(3);
cout << inserted << '\n'; // 0: 3 already exists.
cout << *it << '\n';      // 3

s.emplace(7);
cout << s.size() << '\n';  // 5

Tìm kiếm và kiểm tra tồn tại

find(x) trả iterator đến x, hoặc end() nếu không có. count(x) của set chỉ trả 0 hoặc 1.

C++17
1234567
set<int> s = {1, 3, 5};
if (s.find(3) != s.end()) {
    cout << "Found 3\n";
}
if (s.count(4) == 0) {
    cout << "4 is absent\n";
}

Xóa phần tử, kiểm tra rỗng và xóa toàn bộ

C++17
123456789101112
set<int> s = {1, 3, 5, 7};
cout << s.erase(3) << '\n'; // 1: one element removed.
cout << s.erase(9) << '\n'; // 0: key not found.

auto it = s.find(5);
if (it != s.end()) {
    s.erase(it);
}

cout << s.empty() << '\n'; // 0: still contains 1, 7.
s.clear();
cout << s.size() << '\n';  // 0

3. Map và các thao tác

Mỗi phần tử của map là một cặp key và value. Hai khóa khác nhau có thể lưu cùng một value. Khi duyệt, map sắp theo key, kể cả khi value là số lần xuất hiện hay điểm số.

Thêm, truy cập và cập nhật bằng dấu []

C++17
12345678
map<string, int> score;
score["An"] = 8;  // Add a new key.
score["Binh"] = 8;
score["An"] = 10; // Update the existing value.
cout << score["An"] << '\n'; // 10

cout << score["Chi"] << '\n'; // 0, and key "Chi" is created.
cout << score.size() << '\n';  // 3

Chú ý dấu []. Nếu khóa chưa có, mp[key] tạo khóa và khởi tạo value theo kiểu của nó, chẳng hạn 0 với int hoặc chuỗi rỗng với string. Vì vậy, chỉ đọc bằng dấu [] cũng có thể làm map tăng kích thước.

Phân biệt các cách thêm

  • mp[key] = value thêm mới hoặc ghi đè value.
  • mp.insert({key, value}) và mp.emplace(key, value) chỉ thêm khi chưa có khóa. Khóa đã có thì value cũ được giữ lại.
  • mp.insert_or_assign(key, value) thêm mới hoặc ghi đè, có từ C++17.
  • mp.try_emplace(key, ...) chỉ dựng value mới khi khóa chưa có, có từ C++17.
C++17
12345678
map<int, string> name;
name.insert({2, "An"});
auto [it, inserted] = name.insert({2, "Binh"});
cout << inserted << '\n'; // 0
cout << name[2] << '\n';  // An

name.insert_or_assign(2, "Binh");
cout << name[2] << '\n';  // Binh

Tìm kiếm mà không tạo khóa và dùng at

C++17
1234567891011121314
map<string, int> score = {{"An", 10}, {"Binh", 8}};
auto it = score.find("Chi");
if (it == score.end()) {
    cout << "No score for Chi\n";
} else {
    cout << it->first << ' ' << it->second << '\n';
}

cout << score.count("An") << '\n'; // 1
cout << score.at("An") << '\n';    // 10
// score.at("Chi") throws std::out_of_range.

score.erase("Binh");
score.clear();

at(key) không thêm khóa. Nếu khóa không tồn tại, hàm ném ngoại lệ std::out_of_range. Map cũng có size(), empty(), clear() và xóa bằng iterator như set.

Ứng dụng đếm tần suất

C++17
123456789101112
int a[] = {2, 3, 2, 5, 3, 2};
map<int, int> frequency;
for (int x : a) {
    ++frequency[x];
}

for (const auto& [value, count] : frequency) {
    cout << value << ' ' << count << '\n';
}
// 2 3
// 3 2
// 5 1

Với khóa chưa có, value ban đầu bằng 0 nên ++frequency[x] tăng thành 1. Nếu chỉ kiểm tra tồn tại, dùng find hoặc count. Điều kiện if (mp[x]) vừa có thể tạo khóa vừa không phân biệt được “khóa không có” với “khóa có value bằng 0”.

4. Iterator và cách duyệt

Iterator có thể hiểu là vị trí trỏ đến một phần tử trong cấu trúc. begin() trỏ đến phần tử đầu, còn end() là mốc sau phần tử cuối. Đọc *end() là không hợp lệ.

C++17
1234567891011121314151617
set<int> s = {1, 3, 5};
for (int x : s) {
    cout << x << ' '; // 1 3 5
}

for (auto it = s.rbegin(); it != s.rend(); ++it) {
    cout << *it << ' '; // 5 3 1
}

map<string, int> score = {{"An", 8}, {"Binh", 9}};
for (const auto& [name, points] : score) {
    cout << name << ' ' << points << '\n';
}

for (auto& [name, points] : score) {
    ++points; // Values can be modified; keys cannot.
}
  • Với set, *it là giá trị. Với map, it->first là khóa và it->second là value.
  • Iterator hỗ trợ ++it, --it. Muốn lùi phải chắc chắn chưa ở begin(). Muốn lấy prev(end()) phải chắc chắn cấu trúc không rỗng.
  • Set và map không hỗ trợ truy cập theo thứ tự bằng it + k. Dùng next(it, k) hoặc advance cần đi qua từng bước. Lấy phần tử thứ k theo cách đó mất O(k).
  • mp[3] truy cập khóa 3. Set không có toán tử [].
  • Thêm phần tử không làm mất hiệu lực iterator cũ. Xóa chỉ làm mất hiệu lực iterator hoặc tham chiếu đến phần tử bị xóa.

Lấy phần tử đầu, cuối và xóa trong lúc duyệt

C++17
1234567891011121314
set<int> s = {1, 2, 3, 4, 5};
if (!s.empty()) {
    cout << *s.begin() << '\n';  // 1
    cout << *s.rbegin() << '\n'; // 5
}

for (auto it = s.begin(); it != s.end(); ) {
    if (*it % 2 == 0) {
        it = s.erase(it); // Returns the next iterator.
    } else {
        ++it;
    }
}
// Remaining elements: 1, 3, 5.

Với map, khóa nhỏ nhất là mp.begin()->first và khóa lớn nhất là mp.rbegin()->first, khi map không rỗng và dùng thứ tự tăng dần mặc định.

5. lower_bound và upper_bound

Với thứ tự tăng dần mặc định, hai hàm thành viên sau chạy trong O(log n). Cả set và map đều hỗ trợ, trong đó map tìm theo khóa.

Nhu cầuCách tìmĐiều kiện kiểm tra
Giá trị nhỏ nhất ≥ xlower_bound(x)Iterator khác end()
Giá trị nhỏ nhất > xupper_bound(x)Iterator khác end()
Giá trị lớn nhất ≤ xLùi một bước từ upper_bound(x)Iterator ban đầu khác begin()
Giá trị lớn nhất < xLùi một bước từ lower_bound(x)Iterator ban đầu khác begin()
C++17
1234567891011121314151617181920
set<int> s = {2, 5, 8, 11};
auto lo = s.lower_bound(5);
auto hi = s.upper_bound(5);
cout << *lo << '\n'; // 5
cout << *hi << '\n'; // 8

int x = 7;
auto it = s.upper_bound(x);
if (it != s.begin()) {
    --it;
    cout << *it << '\n'; // 5: largest value <= 7.
} else {
    cout << "No suitable value\n";
}

map<int, string> labels = {{2, "A"}, {8, "B"}};
auto nextLabel = labels.lower_bound(5);
if (nextLabel != labels.end()) {
    cout << nextLabel->first << '\n'; // 8
}

Ưu tiên s.lower_bound(x) và s.upper_bound(x). Các hàm chung như std::lower_bound(s.begin(), s.end(), x) có thể phải di chuyển iterator tuyến tính trên set/map, dù số phép so sánh vẫn là logarithm. Đây là thao tác chính trong bài Concert Tickets.

6. Thứ tự sắp xếp và khóa phức hợp

Sắp xếp giảm dần

C++17
1234567
set<int, greater<int>> s = {1, 5, 3};
for (int x : s) cout << x << ' '; // 5 3 1

map<int, string, greater<int>> names;
names[2] = "B";
names[7] = "G";
// Key order: 7, 2.

Khi dùng comparator khác, begin() là phần tử đầu theo comparator đó. Với greater, đó là phần tử lớn nhất. Các bound cũng tuân theo comparator. Trong thứ tự giảm dần, lower_bound(x) tìm phần tử đầu tiên ≤ x, còn upper_bound(x) tìm phần tử đầu tiên < x.

Dùng pair làm khóa

C++17
12345678
set<pair<int, int>> points;
points.insert({2, 3});
points.insert({1, 9});
points.insert({2, 1});
// Order: (1, 9), (2, 1), (2, 3).

map<pair<int, int>, int> countAt;
++countAt[{2, 3}];

Với comparator mặc định, pair so sánh thành phần thứ nhất trước, bằng nhau mới xét thành phần thứ hai. Chuỗi được sắp theo thứ tự từ điển của phép so sánh C++, không tự sắp theo quy tắc từ điển tiếng Việt.

Hai khóa được coi là trùng khi comp(a, b) và comp(b, a) đều false. Nếu tự viết comparator, phải bảo đảm thứ tự yếu nghiêm ngặt, gồm comp(a, a) == false và tính bắc cầu. Dùng < thay vì <= khi biểu diễn quan hệ đứng trước.

7. Bảng độ phức tạp

Gọi n là số phần tử hiện tại. Bảng dưới áp dụng cho set và map với các lời gọi thông thường, không dùng hint.

Thao tácĐộ phức tạpGhi chú
size(), empty()O(1)Lấy kích thước hoặc kiểm tra rỗng
begin(), end(), rbegin()O(1)Lấy iterator, phải kiểm tra trước khi đọc
find(x), count(x)O(log n)Count của set/map trả 0 hoặc 1
insert, emplaceO(log n)Thêm một phần tử
mp[key], mp.at(key)O(log n)[] có thể chèn khóa mới
lower_bound, upper_boundO(log n)Dùng hàm thành viên
erase(key)O(log n)Set/map xóa tối đa một phần tử
erase(it)O(1) khấu haoĐã có iterator hợp lệ, chưa tính chi phí tìm
clear(), duyệt toàn bộO(n)Bộ nhớ của cấu trúc là O(n)

Khấu hao nghĩa là xét chi phí trung bình trên một chuỗi thao tác. Nếu tìm bằng find rồi xóa iterator đó, cả quá trình vẫn tốn O(log n).

8. Multiset trong các bài tập

multiset có thao tác và thứ tự như set, đồng thời cho phép nhiều phần tử bằng nhau. Cần dùng trong Concert Tickets và Traffic Lights để giữ nhiều vé cùng giá hoặc nhiều khoảng cùng độ dài.

C++17
12345678910
multiset<int> values = {3, 3, 8};
cout << values.count(3) << '\n'; // 2

auto it = values.find(3);
if (it != values.end()) values.erase(it);
// Remaining: 3, 8.

values.insert(3);
values.erase(3); // Removes ALL occurrences of 3.
// Remaining: 8.

Với k phần tử bằng khóa x, multiset.count(x) và multiset.erase(x) có độ phức tạp O(log n + k). Xóa đúng một lần xuất hiện thì dùng erase(it).

  • Set chỉ lưu sự tồn tại. Khi cần số lần lặp, dùng map đếm hoặc multiset.
  • Thêm cùng khóa vào map bằng insert không ghi đè. Muốn cập nhật, dùng [] hoặc insert_or_assign.
  • Không thay đổi trực tiếp phần tử set hoặc khóa map qua iterator. Giá trị map có thể cập nhật bằng it->second.
  • Kiểm tra rỗng trước khi lấy đầu/cuối, kiểm tra end() trước khi đọc iterator và begin() trước khi lùi.
  • Sau khi xóa phần tử, không tiếp tục dùng iterator đã trỏ đến phần tử đó. Trong vòng lặp, nhận iterator kế tiếp từ erase(it).
  • contains có từ C++20. Code C++17 trong tài liệu dùng find hoặc count.
  • Dùng long long khi khóa là tổng tiền tố lớn hoặc value đếm số đoạn có thể vượt giới hạn int.

Đối chiếu quy tắc của thư viện trong bản thảo chuẩn C++ về associative containers và truy cập phần tử map. Các ví dụ ở đây dùng những thao tác có trong C++17.

Phần bài tập bên dưới đi từ thao tác trực tiếp đến kết hợp map/set với tham lam, cửa sổ trượt và tổng tiền tố. Code CSES là chương trình hoàn chỉnh, còn code LeetCode là lớp Solution để nộp trực tiếp.

Bài tập

Bài 1. CSES - Distinct Numbers

Tóm tắt

  • Cho \(n\) số nguyên, đếm số giá trị khác nhau. Giới hạn \(n\le 2\cdot10^5\), \(1\le a_i\le10^9\).
  • Dòng đầu chứa \(n\). Dòng tiếp theo chứa \(n\) số nguyên \(a_i\). In số giá trị phân biệt.

Input

5
2 3 2 2 3

Output

2

Giải thích

Mảng \([2,3,2,2,3]\) có hai giá trị khác nhau là \(2\) và \(3\). Kết quả là \(2\).

Lời giải
  1. Thêm mọi phần tử vào set<long long>. Vì set chỉ lưu một bản của mỗi giá trị, số phần tử trong set chính là đáp án.
  2. Khởi tạo set rỗng. Đọc từng số và gọi insert. Sau khi đọc hết, in size().
  3. Mỗi giá trị xuất hiện trong mảng được thêm vào set. Những lần xuất hiện tiếp theo của cùng giá trị không làm tăng kích thước. Do đó mỗi giá trị phân biệt được đếm đúng một lần.

Code mẫu

C++17
1234567891011121314151617181920
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    set<long long> values;

    for (int i = 0; i < n; ++i) {
        long long x;
        cin >> x;
        values.insert(x);
    }

    cout << values.size() << '\n';
    return 0;
}

Độ phức tạp

\(O(n\log n)\) thời gian và \(O(n)\) bộ nhớ phụ trong trường hợp xấu nhất.

Lưu ý

Giá trị lớn đến \(10^9\) khiến mảng đánh dấu trực tiếp theo giá trị trở nên tốn bộ nhớ. Set lưu những giá trị thực sự xuất hiện.

Bài 2. LeetCode - Valid Anagram

Tóm tắt

  • Cho hai chuỗi chữ cái tiếng Anh thường \(s,t\). Kiểm tra có thể hoán vị các ký tự của \(s\) để được \(t\) hay không. Độ dài mỗi chuỗi không quá \(5\cdot10^4\).
  • Hai tham số của hàm là chuỗi s và t. Trả về giá trị boolean.

Input

s = "anagram", t = "nagaram"

Output

true

Giải thích

anagram và nagaram trả true. rat và car trả false.

Lời giải
  1. Dùng map<char,int> lưu chênh lệch tần suất. Mỗi ký tự trong \(s\) cộng một, mỗi ký tự trong \(t\) trừ một. Hai chuỗi hợp lệ khi mọi chênh lệch đều bằng không.
  2. Nếu độ dài khác nhau, trả false. Đếm tăng theo \(s\), đếm giảm theo \(t\), rồi duyệt map để kiểm tra.
  3. Hoán vị giữ nguyên số lượng từng ký tự. Ngược lại, khi hai chuỗi có cùng số lượng của mọi ký tự, có thể sắp xếp lại các ký tự của chuỗi này để tạo chuỗi kia. Chênh lệch bằng không kiểm tra đúng điều kiện đó.

Code mẫu

class Solution {
public:
    bool isAnagram(string s, string t) {
        if (s.size() != t.size()) {
            return false;
        }

        map<char, int> difference;
        for (char c : s) {
            ++difference[c];
        }
        for (char c : t) {
            --difference[c];
        }

        for (const auto& entry : difference) {
            if (entry.second != 0) {
                return false;
            }
        }
        return true;
    }
};

Độ phức tạp

Với \(n=|s|+|t|\) và \(\sigma\) là số ký tự khác nhau, thời gian \(O(n\log(\sigma+1))\), bộ nhớ \(O(\sigma)\). Trong đề này \(\sigma\le26\) nên thời gian là \(O(n)\).

Lưu ý

Set chỉ lưu ký tự nào đã xuất hiện. Bài này cần biết cả số lần xuất hiện nên dùng map đếm tần suất. Với bảng chữ cái cố định, mảng 26 phần tử cũng giải được bài.

Bài 3. LeetCode - Intersection of Two Arrays

Tóm tắt

  • Cho hai mảng số nguyên. Trả về những giá trị xuất hiện trong cả hai mảng, mỗi giá trị chỉ xuất hiện một lần trong kết quả. Thứ tự kết quả tùy ý. Mỗi mảng có tối đa \(1000\) phần tử.
  • Hai tham số là mảng nums1 và nums2. Trả về mảng chứa các giá trị chung phân biệt, theo thứ tự tùy ý.

Input

nums1 = [1, 2, 2, 1]
nums2 = [2, 2]

Output

[2]

Giải thích

\([1,2,2,1]\) và \([2,2]\) cho kết quả \([2]\).

Lời giải
  1. Đưa các giá trị của mảng thứ nhất vào set. Duyệt mảng thứ hai, nếu tìm thấy giá trị trong set thì thêm vào kết quả và xóa giá trị đó khỏi set.
  2. Tạo set từ nums1. Với mỗi x trong nums2, dùng find(x). Nếu tồn tại thì lưu x, sau đó gọi erase(it).
  3. Một giá trị chỉ được thêm vào kết quả khi có trong cả hai mảng. Ngay sau lần thêm đầu tiên, giá trị được xóa khỏi set nên các lần gặp tiếp theo không thể thêm lại. Mọi giá trị chung đều được tìm thấy ở lần xuất hiện đầu tiên trong mảng thứ hai.

Code mẫu

C++17

class Solution {
public:
    vector<int> intersection(vector<int>& nums1,
                             vector<int>& nums2) {
        set<int> available(nums1.begin(), nums1.end());
        vector<int> answer;

        for (int x : nums2) {
            auto it = available.find(x);
            if (it != available.end()) {
                answer.push_back(x);
                available.erase(it);
            }
        }

        return answer;
    }
};

Độ phức tạp

Với hai độ dài \(n,m\), thời gian \(O((n+m)\log(n+1))\), bộ nhớ phụ \(O(n)\), chưa tính mảng kết quả.

Lưu ý

Bài yêu cầu giá trị phân biệt. Nếu đề đổi thành lấy cả số lần lặp trong giao hai mảng, cần quản lý tần suất bằng map hoặc dùng multiset.

Bài 4. CSES - Sum of Two Values

Tóm tắt

  • Cho mảng \(n\) số và mục tiêu \(x\). Tìm hai vị trí khác nhau có tổng bằng \(x\). In hai chỉ số bắt đầu từ \(1\), hoặc IMPOSSIBLE. \(n\le2\cdot10^5\).
  • Dòng đầu chứa \(n,x\). Dòng tiếp theo chứa \(n\) phần tử. In hai chỉ số bắt đầu từ \(1\), hoặc IMPOSSIBLE.

Input

4 8
2 7 5 1

Output

2 4

Giải thích

Với \([2,7,5,1]\), \(x=8\), có thể in \(2\,4\) vì \(7+1=8\).

Lời giải
  1. Khi đang xét \(a_i\), cần tìm giá trị \(x-a_i\) trong những phần tử đã duyệt. Dùng map lưu giá trị và một vị trí đã gặp của nó.
  2. Tìm phần bù trước. Nếu tồn tại thì in vị trí đã lưu và \(i\). Nếu chưa có, mới lưu position[a[i]] = i.
  3. Map chỉ chứa các vị trí nhỏ hơn \(i\), nên hai vị trí luôn khác nhau. Nếu một cặp hợp lệ tồn tại, khi duyệt tới vị trí phía sau, giá trị tại vị trí phía trước đã có trong map và sẽ được tìm ra.

Code mẫu

C++17
123456789101112131415161718192021222324252627
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    long long target;
    cin >> n >> target;
    map<long long, int> position;

    for (int i = 1; i <= n; ++i) {
        long long value;
        cin >> value;
        auto it = position.find(target - value);

        if (it != position.end()) {
            cout << it->second << ' ' << i << '\n';
            return 0;
        }
        position[value] = i;
    }

    cout << "IMPOSSIBLE\n";
    return 0;
}

Độ phức tạp

\(O(n\log n)\) thời gian và \(O(n)\) bộ nhớ phụ.

Lưu ý

Lưu phần tử hiện tại trước khi tìm có thể khiến dùng cùng một vị trí hai lần khi \(2a_i=x\). Tìm trước rồi lưu xử lý đúng cả trường hợp hai giá trị bằng nhau.

Bài 5. CSES - Concert Tickets

Tóm tắt

  • Có \(n\) vé với giá cho trước. Lần lượt \(m\) khách đến, mỗi khách có ngân sách \(t\). Bán cho khách vé đắt nhất có giá \(\le t\), rồi xóa vé đó. Nếu không có vé phù hợp, in \(-1\). \(n,m\le2\cdot10^5\).
  • Dòng đầu chứa \(n,m\). Dòng thứ hai chứa \(n\) giá vé. Dòng thứ ba chứa ngân sách của \(m\) khách. In một kết quả cho mỗi khách.

Input

5 3
5 3 7 8 5
4 8 3

Output

3
8
-1

Giải thích

Vé \([5,3,7,8,5]\), khách \([4,8,3]\) cho kết quả lần lượt \(3,8,-1\).

Lời giải
  1. Dùng multiset để lưu các vé còn lại, kể cả vé trùng giá. upper_bound(t) trỏ đến giá đầu tiên \(>t\), nên phần tử ngay trước nó là giá lớn nhất \(\le t\).
  2. Tìm it = tickets.upper_bound(t). Nếu it == begin(), không có vé phù hợp. Ngược lại giảm iterator, in giá và xóa đúng vé đó bằng erase(it).
  3. Multiset luôn chứa đúng các vé chưa bán. Theo thứ tự tăng dần, phần tử đứng trước giá đầu tiên vượt ngân sách chính là vé đắt nhất khách mua được. Xóa một iterator giữ lại những vé khác cùng giá cho khách sau.

Code mẫu

C++17
123456789101112131415161718192021222324252627282930
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    cin >> n >> m;
    multiset<int> tickets;
    for (int i = 0; i < n; ++i) {
        int price;
        cin >> price;
        tickets.insert(price);
    }

    for (int i = 0; i < m; ++i) {
        int budget;
        cin >> budget;
        auto it = tickets.upper_bound(budget);
        if (it == tickets.begin()) {
            cout << -1 << '\n';
        } else {
            --it;
            cout << *it << '\n';
            tickets.erase(it);
        }
    }
    return 0;
}

Độ phức tạp

\(O((n+m)\log(n+1))\) thời gian, \(O(n)\) bộ nhớ phụ.

Lưu ý

erase(price) xóa mọi vé cùng giá. Dùng tickets.upper_bound để tìm trong \(O(\log n)\), hàm std::upper_bound trên iterator multiset có thể phải di chuyển tuyến tính.

Bài 6. CSES - Playlist

Tóm tắt

  • Cho dãy \(n\) mã bài hát, tìm độ dài đoạn liên tiếp dài nhất không chứa mã trùng nhau. \(n\le2\cdot10^5\).
  • Dòng đầu chứa \(n\). Dòng tiếp theo chứa \(n\) mã bài hát. In độ dài đoạn hợp lệ dài nhất.

Input

8
1 2 1 3 2 7 4 2

Output

5

Giải thích

Dãy \([1,2,1,3,2,7,4,2]\) có đoạn \([1,3,2,7,4]\) dài \(5\).

Lời giải
  1. Duy trì đoạn hợp lệ \([left,right]\). Map lưu vị trí xuất hiện gần nhất của mỗi mã. Khi mã hiện tại từng xuất hiện tại \(p\), đặt \(left=\max(left,p+1)\) để bỏ lần xuất hiện cũ nếu còn nằm trong đoạn.
  2. Với từng \(right\), tìm vị trí cũ rồi cập nhật \(left\). Lưu vị trí mới và cập nhật đáp án bằng \(right-left+1\).
  3. Trước khi thêm phần tử mới, đoạn hiện tại không trùng. Chỉ mã mới thêm có thể gây trùng. Bỏ mọi vị trí đến lần xuất hiện gần nhất của nó sẽ loại đúng sự trùng đó. Cận trái được giữ nhỏ nhất có thể mà đoạn vẫn hợp lệ, nên ta xét đoạn hợp lệ dài nhất kết thúc tại mỗi \(right\).

Code mẫu

C++17
12345678910111213141516171819202122232425262728
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    map<int, int> lastPosition;
    int left = 1;
    int answer = 0;

    for (int right = 1; right <= n; ++right) {
        int song;
        cin >> song;
        auto it = lastPosition.find(song);
        if (it != lastPosition.end()) {
            left = max(left, it->second + 1);
        }

        lastPosition[song] = right;
        answer = max(answer, right - left + 1);
    }

    cout << answer << '\n';
    return 0;
}

Độ phức tạp

\(O(n\log n)\) thời gian, \(O(n)\) bộ nhớ phụ.

Lưu ý

Thiếu max có thể khiến cận trái lùi về trước. Với \([1,2,2,1]\), khi xét số \(1\) cuối cùng, lần xuất hiện cũ đã nằm ngoài đoạn và không được kéo \(left\) lùi lại.

Bài 7. CSES - Subarray Sums II

Tóm tắt

  • Cho mảng \(n\) số nguyên, có thể có số âm. Đếm số đoạn liên tiếp không rỗng có tổng bằng \(x\). \(n\le2\cdot10^5\), \(|a_i|,|x|\le10^9\).
  • Dòng đầu chứa \(n,x\). Dòng tiếp theo chứa \(n\) số nguyên. In số đoạn liên tiếp không rỗng có tổng bằng \(x\).

Input

5 7
2 -1 3 5 -2

Output

2

Giải thích

Với \([2,-1,3,5,-2]\), \(x=7\), hai đoạn hợp lệ là \([-1,3,5]\) và \([3,5,-2]\).

Lời giải
  1. Gọi \(P_i=a_1+\cdots+a_i\), \(P_0=0\). Tổng đoạn \([l,r]\) bằng \(x\) khi \(P_r-P_{l-1}=x\), tức \(P_{l-1}=P_r-x\). Với mỗi tổng tiền tố hiện tại, cần biết có bao nhiêu tổng tiền tố trước đó bằng nó trừ \(x\).
  2. Đặt frequency[0] = 1. Với từng phần tử, cập nhật tổng tiền tố \(P\). Cộng số lần đã gặp giá trị \(P-x\) vào đáp án, rồi tăng tần suất của \(P\).
  3. Trước khi xử lý vị trí \(r\), map đếm đúng \(P_0,\ldots,P_{r-1}\). Mỗi lần xuất hiện của \(P_r-x\) tương ứng duy nhất với một đầu trái hợp lệ. Mỗi đoạn được đếm đúng một lần khi duyệt đến đầu phải của nó.

Code mẫu

C++17
1234567891011121314151617181920212223242526272829
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    long long target;
    cin >> n >> target;
    map<long long, long long> frequency;
    frequency[0] = 1;
    long long prefix = 0;
    long long answer = 0;

    for (int i = 0; i < n; ++i) {
        long long value;
        cin >> value;
        prefix += value;
        auto it = frequency.find(prefix - target);
        if (it != frequency.end()) {
            answer += it->second;
        }
        ++frequency[prefix];
    }

    cout << answer << '\n';
    return 0;
}

Độ phức tạp

\(O(n\log n)\) thời gian, \(O(n)\) bộ nhớ phụ.

Lưu ý

Quên \(P_0=0\) sẽ bỏ sót các đoạn bắt đầu từ phần tử đầu tiên. Tăng tần suất trước khi đếm có thể đếm cả đoạn rỗng khi \(x=0\). Tổng tiền tố và đáp án phải dùng long long.

Bài 8. CSES - Traffic Lights

Tóm tắt

  • Con đường từ \(0\) đến \(x\) ban đầu chưa có đèn. Thêm \(n\) đèn tại những vị trí phân biệt nằm trong đường. Sau mỗi lần thêm, in độ dài khoảng không có đèn dài nhất. \(n\le2\cdot10^5\), \(x\le10^9\).
  • Dòng đầu chứa độ dài đường \(x\) và số đèn \(n\). Dòng tiếp theo chứa \(n\) vị trí theo thứ tự thêm. In \(n\) độ dài lớn nhất tương ứng.

Input

8 3
3 6 2

Output

5 3 3

Giải thích

\(x=8\), thêm đèn tại \(3,6,2\) thì kết quả lần lượt là \(5,3,3\).

Lời giải
  1. Set lưu các vị trí, ban đầu gồm \(0,x\). Multiset lưu độ dài khoảng trống, ban đầu có \(x\). Khi thêm \(p\), tìm hai vị trí kề \(L<p<R\) bằng upper_bound. Xóa một độ dài \(R-L\), thêm \(p-L\) và \(R-p\), rồi thêm \(p\) vào set. Giá trị lớn nhất trong multiset là đáp án.
  2. Mỗi đèn mới chỉ chia khoảng chứa nó thành hai khoảng. Các khoảng khác được giữ nguyên. Cập nhật trên duy trì đúng tập các độ dài hiện tại, bao gồm những độ dài bằng nhau, nên phần tử lớn nhất chính là khoảng dài nhất.

Code mẫu

C++17
1234567891011121314151617181920212223242526272829303132
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int roadLength, n;
    cin >> roadLength >> n;
    set<int> positions = {0, roadLength};
    multiset<int> gaps = {roadLength};

    for (int i = 0; i < n; ++i) {
        int p;
        cin >> p;
        auto rightIt = positions.upper_bound(p);
        auto leftIt = prev(rightIt);
        int left = *leftIt;
        int right = *rightIt;

        auto oldGap = gaps.find(right - left);
        gaps.erase(oldGap);
        gaps.insert(p - left);
        gaps.insert(right - p);
        positions.insert(p);

        if (i > 0) cout << ' ';
        cout << *gaps.rbegin();
    }
    cout << '\n';
    return 0;
}

Độ phức tạp

\(O(n\log n)\) thời gian và \(O(n)\) bộ nhớ phụ.

Lưu ý

Phải xóa đúng một khoảng bằng iterator vì nhiều khoảng có thể cùng độ dài. Hai mốc \(0,x\) bảo đảm luôn có hàng xóm hai phía. Code dựa vào điều kiện đề bảo đảm các vị trí thêm vào phân biệt và nằm trong \((0,x)\).

Thứ tự độ khó là gợi ý cho việc học. Đề gốc được liên kết ở tên từng bài.
