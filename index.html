Tổng quan

Giả sử bạn nhận được dãy 5, 2, 5, 8, 2. Hai câu hỏi thường gặp là “Có những số nào?” và “Mỗi số xuất hiện bao nhiêu lần?”. set giúp trả lời câu thứ nhất, còn map giúp lưu thông tin để trả lời câu thứ hai.

Phần này dành cho bạn đã biết biến, mảng, if và vòng lặp for. Mỗi ví dụ được giải thích ngay bên dưới. Bạn có thể đọc lần lượt từ mục 1 đến mục 5 rồi thử các bài tập cơ bản.

1. Hiểu set và map qua một ví dụ

Set lưu các giá trị khác nhau

Hãy hình dung set là một danh sách tự giữ thứ tự và tự bỏ các giá trị trùng. Thêm lần lượt các số 5, 2, 5, 8, 2 vào set, bạn sẽ có các giá trị 2, 5, 8.

  • Thêm số 5 lần đầu, set nhận số 5.
  • Thêm số 5 lần nữa, set vẫn giữ một số 5.
  • Khi duyệt set theo cách thông thường, các số hiện ra theo thứ tự tăng dần.

Map gắn mỗi khóa với một giá trị

Hãy hình dung map là một cuốn sổ. Mỗi dòng có một nhãn để tra cứu và một thông tin đi kèm.

  • Key, hay khóa, là nhãn dùng để tra cứu.
  • Value, hay giá trị, là thông tin được lưu cho khóa đó.

Để đếm dãy trên, chọn key là số trong dãy và value là số lần xuất hiện.

Key — số cần đếmValue — số lần xuất hiện
22
52
81

Mỗi key có một value tại một thời điểm. Key 2 và key 5 đều có value bằng 2 là hoàn toàn hợp lệ. Khi duyệt map theo cách thông thường, thứ tự dựa vào key.

Cần thư viện nào?

Các ví dụ trong phần này dùng C++17. Để chạy một ví dụ, dùng khung chương trình sau rồi đặt đoạn thao tác cần thử vào trong main(). Mỗi ví dụ là một lần chạy riêng.

C++17
12345678910
#include <iostream>
#include <set>
#include <map>
#include <string>
using namespace std;

int main() {
    // Đặt đoạn code muốn thử ở đây.
    return 0;
}

2. Set từ khai báo đến sử dụng

Bước 1. Tạo set và thêm phần tử

C++17
1234567
set<int> s;
s.insert(5);
s.insert(2);
s.insert(5);
s.insert(8);

cout << s.size() << '\n';

Kết quả

3
  • set<int> s; tạo một set rỗng tên s, dùng để lưu các số nguyên.
  • s.insert(x) thêm giá trị x. Nếu x đã có thì số phần tử không tăng.
  • s.size() trả số phần tử đang lưu. Set trên có ba giá trị 2, 5, 8.

Bước 2. Duyệt để in toàn bộ

C++17
1234
set<int> s = {5, 2, 5, 8};
for (int x : s) {
    cout << x << ' ';
}

Kết quả

2 5 8

for (int x : s) có thể đọc là “lấy lần lượt từng giá trị trong s, đặt vào biến x rồi chạy phần thân vòng lặp”. Set mặc định giữ các giá trị tăng dần, nên 2 được in trước 5 và 8.

Bước 3. Kiểm tra một số có xuất hiện không

C++17
1234567
set<int> s = {2, 5, 8};
if (s.count(5) == 1) {
    cout << "Co so 5\n";
}
if (s.count(7) == 0) {
    cout << "Khong co so 7\n";
}

s.count(x) trả 1 nếu x có trong set và trả 0 nếu không có. Vì set chỉ giữ một bản của mỗi giá trị, kết quả luôn là 0 hoặc 1.

Bước 4. Xóa và kiểm tra rỗng

C++17
123456789
set<int> s = {2, 5, 8};
s.erase(5);  // Còn 2, 8.
s.erase(7);  // 7 chưa có, set vẫn giữ nguyên.

cout << s.size() << '\n';  // In 2.
cout << s.empty() << '\n'; // In 0, nghĩa là false.

s.clear();
cout << s.empty() << '\n'; // In 1, nghĩa là true.

erase(x) xóa giá trị x, clear() xóa toàn bộ. empty() trả true khi không còn phần tử nào. Khi in boolean bằng cout mặc định, true hiện thành 1 và false hiện thành 0.

Bài áp dụng ngay

Muốn đếm số giá trị khác nhau của một mảng, thêm mọi phần tử vào set rồi lấy size(). Đây chính là cách làm bài Distinct Numbers.

3. Map, key và value

Bước 1. Chọn thông tin làm key và value

Ví dụ cần lưu điểm của từng bạn. Chọn tên làm key, điểm làm value. Vì tên là chuỗi và điểm là số nguyên, ta khai báo map<string, int>.

C++17
12345678
map<string, int> diem;
diem["An"] = 8;
diem["Binh"] = 9;

cout << diem["An"] << '\n';
diem["An"] = 10;
cout << diem["An"] << '\n';
cout << diem.size() << '\n';

Kết quả

8
10
2
  • diem["An"] là điểm gắn với tên An.
  • Gán 8 rồi gán 10 cho cùng key An sẽ cập nhật điểm. Map vẫn chỉ có hai key là An và Binh.
  • size() của map đếm số key đang được lưu.

Dấu [] ở map tra theo key. Với map<int, int> mp, mp[100] là value của key 100. Bạn có thể dùng key 100 ngay cả khi map mới có một phần tử.

Bước 2. Hiểu chuyện gì xảy ra khi key chưa có

C++17
1234
map<string, int> diem;
cout << diem.size() << '\n';
cout << diem["Chi"] << '\n';
cout << diem.size() << '\n';

Kết quả

0
0
1

Ban đầu map rỗng. Dòng diem["Chi"] tạo key Chi và đặt điểm ban đầu bằng 0 vì value có kiểu int. Do đó kích thước tăng từ 0 lên 1 dù bạn chỉ muốn đọc điểm.

Nếu value có kiểu string, giá trị được tạo ban đầu là chuỗi rỗng. Khi chỉ muốn kiểm tra một key có tồn tại không, dùng count hoặc find.

C++17
12345678
map<string, int> diem = {{"An", 0}};
if (diem.count("An") == 1) {
    cout << "Da luu diem cua An\n";
}
if (diem.count("Chi") == 0) {
    cout << "Chua luu diem cua Chi\n";
}
cout << diem.size() << '\n'; // Vẫn là 1.

An có điểm bằng 0 nhưng key An vẫn tồn tại. Vì vậy, kiểm tra diem["An"] != 0 sẽ không trả lời đúng câu hỏi “đã lưu An chưa?”.

Bước 3. Dùng map để đếm tần suất

Tần suất ở đây là số lần một giá trị xuất hiện. Với dãy 5, 2, 5, 8, 2, dùng key là số cần đếm và value là số lần đã gặp nó.

C++17
12345678910
int a[] = {5, 2, 5, 8, 2};
map<int, int> dem;

for (int x : a) {
    dem[x]++;
}

cout << dem[2] << '\n';
cout << dem[5] << '\n';
cout << dem[8] << '\n';

Kết quả

2
2
1
Số vừa đọcThay đổi trong map
5Chưa có key 5, tạo với value 0 rồi tăng thành 1.
2Chưa có key 2, tạo với value 0 rồi tăng thành 1.
5Đã có key 5, tăng value từ 1 lên 2.
8Chưa có key 8, tạo với value 0 rồi tăng thành 1.
2Đã có key 2, tăng value từ 1 lên 2.

Bước 4. Duyệt map để in các cặp key và value

C++17
1234
map<int, int> dem = {{5, 2}, {2, 2}, {8, 1}};
for (auto phanTu : dem) {
    cout << phanTu.first << ' ' << phanTu.second << '\n';
}

Kết quả

2 2
5 2
8 1
  • auto nhờ C++ tự suy ra kiểu biến. Ở đây mỗi phanTu là một cặp.
  • phanTu.first lấy key, phanTu.second lấy value.
  • Key 2 được in trước key 5 vì map mặc định sắp tăng theo key. Các value không được dùng để quyết định thứ tự này.

Bước 5. Xóa và thêm bằng insert

C++17
12345678910
map<string, int> diem;
diem.insert({"An", 8});
diem.insert({"An", 10});
cout << diem["An"] << '\n'; // Vẫn là 8.

diem["An"] = 10;
cout << diem["An"] << '\n'; // Thành 10.

diem.erase("An"); // Xóa cả key An và điểm đi kèm.
diem.clear();     // Xóa toàn bộ map.

insert({key, value}) chỉ thêm nếu chưa có key. Muốn cập nhật value của key đã có, bạn có thể gán bằng mp[key] = value. Map cũng có empty() như set.

4. Iterator là gì và dùng thế nào?

Iterator là một biến giúp bạn theo dõi một vị trí trong set hoặc map. Tạm hình dung nó như ngón tay đang chỉ vào một phần tử. Từ vị trí đó, bạn có thể đọc phần tử hoặc đi sang phần tử kế tiếp.

  • begin() cho iterator đến phần tử đầu.
  • end() là mốc nằm sau phần tử cuối, dùng để nhận biết đã hết.
  • ++it đi tới phần tử kế tiếp, --it lùi về phần tử trước.
  • Với set, *it đọc giá trị ở vị trí iterator đang trỏ tới.

Tìm một phần tử bằng find

C++17
123456
set<int> s = {2, 5, 8};
auto it = s.find(5);

if (it != s.end()) {
    cout << *it << '\n'; // In 5.
}

find(5) trả iterator đến số 5 nếu tìm thấy. Nếu không tìm thấy, nó trả s.end(). Điều kiện it != s.end() nghĩa là “đã tìm được”, lúc đó mới được đọc *it.

Duyệt bằng iterator

C++17
1234
set<int> s = {2, 5, 8};
for (auto it = s.begin(); it != s.end(); ++it) {
    cout << *it << ' ';
}

Vòng lặp bắt đầu ở số 2, in số đang trỏ tới, rồi đi sang 5 và 8. Sau số 8, iterator chạm mốc end() nên vòng lặp dừng. Bạn có thể dùng for-each như mục 2 khi chỉ cần duyệt toàn bộ.

Iterator của map đọc key và value thế nào?

C++17
1234567
map<string, int> diem = {{"An", 8}, {"Binh", 9}};
auto it = diem.find("An");
if (it != diem.end()) {
    cout << it->first << '\n';  // An
    cout << it->second << '\n'; // 8
    it->second = 10;             // Cập nhật điểm của An.
}

Khi dùng iterator của map, it->first là key và it->second là value. Dấu -> giúp đọc thành phần của cặp mà iterator đang trỏ đến.

Hai điều phải kiểm tra trước khi đọc hoặc lùi iterator

  • Chỉ đọc *it hoặc it->... khi it khác end().
  • Chỉ lùi --it khi it chưa ở begin().
C++17
12345
set<int> s = {2, 5, 8};
if (!s.empty()) {
    cout << *s.begin() << '\n';  // Nhỏ nhất, in 2.
    cout << *s.rbegin() << '\n'; // Lớn nhất, in 8.
}

!s.empty() nghĩa là set có ít nhất một phần tử. Với thứ tự tăng dần mặc định, phần tử đầu là nhỏ nhất và phần tử đầu khi duyệt ngược bằng rbegin() là lớn nhất.

5. Tìm phần tử gần x bằng các hàm bound

find(x) cần tìm đúng x. Có những bài cần tìm một giá trị thỏa điều kiện như “số nhỏ nhất mà vẫn ≥ x”. Khi đó dùng các hàm bound.

Xét set {2, 5, 8, 11}, được sắp tăng dần.

Lời gọiCâu hỏi cần trả lờiKết quả
s.lower_bound(5)Phần tử nhỏ nhất ≥ 5?Iterator đến 5
s.upper_bound(5)Phần tử nhỏ nhất > 5?Iterator đến 8
s.lower_bound(6)Phần tử nhỏ nhất ≥ 6?Iterator đến 8
s.upper_bound(11)Phần tử nhỏ nhất > 11?end() vì không có
C++17
12345
set<int> s = {2, 5, 8, 11};
auto it = s.lower_bound(6);
if (it != s.end()) {
    cout << *it << '\n'; // In 8.
}

Cả hai hàm trả iterator, nên muốn lấy số phải đọc *it sau khi kiểm tra.

Tìm số lớn nhất không vượt quá x

Ví dụ có 7 đồng, muốn chọn giá vé cao nhất vẫn mua được. Tìm giá đầu tiên > 7, rồi lùi một phần tử sẽ được giá lớn nhất ≤ 7.

C++17
12345678910
set<int> s = {2, 5, 8, 11};
int x = 7;
auto it = s.upper_bound(x); // Trỏ tới 8.

if (it == s.begin()) {
    cout << "Khong co gia phu hop\n";
} else {
    --it;
    cout << *it << '\n'; // In 5.
}

Nếu iterator đã là begin(), mọi giá đều vượt x nên không có phần tử để lùi tới. Nếu upper_bound trả end() và set không rỗng, bạn vẫn có thể lùi để lấy phần tử cuối.

Map có các hàm bound giống vậy, nhưng tìm theo key. Khi lấy kết quả, đọc key bằng it->first và value bằng it->second.

6. Khi cần giữ cả các phần tử trùng

Giả sử có ba vé giá 5, 5, 8. Bạn cần giữ cả hai vé giá 5, vì bán một vé thì vẫn còn một vé nữa. Dùng multiset để lưu được các bản trùng.

C++17
123456789
multiset<int> ve = {5, 5, 8};
cout << ve.size() << '\n';  // 3 vé.
cout << ve.count(5) << '\n'; // 2 vé có giá 5.

auto it = ve.find(5);
if (it != ve.end()) {
    ve.erase(it); // Chỉ bán một vé giá 5.
}
cout << ve.count(5) << '\n'; // Còn một vé giá 5.

Phân biệt hai cách xóa. ve.erase(5) xóa mọi vé giá 5. ve.erase(it) chỉ xóa đúng vé mà iterator trỏ tới. Phải kiểm tra it != ve.end() trước khi xóa bằng iterator.

Multiset cũng được sắp tăng dần mặc định và hỗ trợ find, lower_bound, upper_bound. Đây là cấu trúc dùng trong Concert Tickets.

7. Các thao tác nhanh đến mức nào?

Gọi n là số phần tử đang lưu. “Độ phức tạp” mô tả lượng công việc tăng như thế nào khi n tăng.

  • O(1) là lượng công việc không tăng theo n.
  • O(log n) tăng chậm khi n tăng, phù hợp cho việc tìm kiếm, thêm hoặc xóa nhiều lần.
  • O(n) tăng theo n, chẳng hạn duyệt toàn bộ các phần tử.
Thao tác trên set/mapCách viếtĐộ phức tạp
Đếm phần tử, kiểm tra rỗngsize(), empty()O(1)
Kiểm tra có khóa hay khôngcount(x), find(x)O(log n)
Thêm một phần tử thông thườnginsert(...)O(log n)
Xóa theo khóaerase(x)O(log n)
Tìm giá trị theo điều kiệnlower_bound(x), upper_bound(x)O(log n)
Truy cập value của mapmp[key]O(log n)
Duyệt hoặc xóa toàn bộVòng lặp, clear()O(n)

Ví dụ, thêm n số vào set có tổng thời gian O(n log n), vì thực hiện n lần thêm và mỗi lần tốn tối đa O(log n). Bộ nhớ lưu cấu trúc là O(n).

Bảng trên dành cho khóa có chi phí so sánh xem như hằng số, chẳng hạn số nguyên. Với khóa chuỗi, so sánh còn phụ thuộc độ dài chuỗi. Multiset đếm hoặc xóa k bản có cùng giá trị tốn O(log n + k).

Những điều nên tự hỏi khi code

  1. Mình cần sự tồn tại hay số lần xuất hiện? Set giúp kiểm tra tồn tại. Khi cần số lần, dùng map đếm hoặc multiset.
  2. Mình đang tra theo key nào? Map sắp theo key. mp[3] tra key 3, còn truy cập phần tử thứ ba theo thứ tự cần duyệt.
  3. Dòng [] này có đang tạo key mới không? Nếu chỉ kiểm tra tồn tại, dùng find hoặc count.
  4. Iterator có hợp lệ để đọc không? Kiểm tra khác end(), kiểm tra cấu trúc có rỗng không khi lấy đầu/cuối.
  5. Mình muốn xóa một hay mọi bản trùng? Với multiset, dùng erase(it) để xóa một bản.
  6. Số cần lưu có vượt int không? Dùng long long cho tổng lớn hoặc số lượng đoạn có thể vượt khoảng 2,1 tỷ.

9. Đọc thêm sau khi đã nắm phần cơ bản

Các mục dưới giúp bạn tra cứu khi gặp yêu cầu mới. Bạn có thể quay lại sau khi làm các bài đầu tiên.

Thay đổi thứ tự và dùng pair làm khóa

Set và map mặc định sắp tăng dần. Muốn giảm dần, thêm greater và thư viện <functional>. Muốn dùng pair, thêm <utility>.

C++17
12345678910
set<int, greater<int>> s = {2, 5, 8};
// Duyệt theo thứ tự 8, 5, 2.

map<int, string, greater<int>> ten;
ten[2] = "An";
ten[5] = "Binh";
// Key 5 đứng trước key 2.

set<pair<int, int>> toaDo = {{2, 3}, {1, 9}, {2, 1}};
// Thứ tự (1, 9), (2, 1), (2, 3).

Pair so sánh thành phần thứ nhất trước, bằng nhau mới so sánh thành phần thứ hai. Chuỗi dùng thứ tự từ điển của phép so sánh C++, không tự áp dụng quy tắc từ điển tiếng Việt.

Khi dùng greater, begin() trỏ đến phần tử lớn nhất. Trong thứ tự giảm dần, lower_bound(x) tìm phần tử đầu tiên ≤ x và upper_bound(x) tìm phần tử đầu tiên < x.

Nếu tự viết hàm so sánh, nó phải tạo thứ tự yếu nghiêm ngặt. Trong đó, comp(a, a) phải false và quan hệ đứng trước phải có tính bắc cầu. Hai khóa được coi là trùng khi cả comp(a, b) lẫn comp(b, a) đều false.

Các cách thêm và truy cập khác
  • emplace(...) tạo phần tử từ các tham số truyền vào rồi thử thêm. Set/map vẫn giữ khóa duy nhất.
  • insert và emplace trên set/map trả một cặp. Thành phần first là iterator tới phần tử, second cho biết có thêm mới thành công hay không.
  • mp.at(key) đọc hoặc sửa value mà không tạo key. Thiếu key thì ném ngoại lệ std::out_of_range.
  • insert_or_assign(key, value) thêm hoặc cập nhật, có từ C++17.
  • try_emplace(key, ...) chỉ dựng value mới khi chưa có key, có từ C++17.
  • contains(x) có từ C++20. Với C++17, dùng find hoặc count.
Sửa dữ liệu và xóa khi đang duyệt

Bạn sửa được value của map qua it->second. Để giữ thứ tự hợp lệ, phần tử set và key của map không được sửa trực tiếp qua iterator. Có thể xóa phần tử cũ rồi thêm phần tử mới.

Thêm phần tử không làm mất hiệu lực iterator cũ. Khi xóa, iterator đến phần tử vừa xóa không dùng được nữa. Dùng kết quả trả về của erase(it) để đi tiếp an toàn.

C++17
123456789
set<int> s = {1, 2, 3, 4, 5};
for (auto it = s.begin(); it != s.end(); ) {
    if (*it % 2 == 0) {
        it = s.erase(it); // Xóa và nhận vị trí tiếp theo.
    } else {
        ++it;
    }
}
// Còn 1, 3, 5.

Khi đã có iterator hợp lệ, erase(it) tốn O(1) khấu hao. “Khấu hao” xét chi phí trên cả một chuỗi thao tác. Nếu tìm bằng find rồi xóa, tổng vẫn tốn O(log n) vì bước tìm.

Vì sao dùng hàm bound của set/map?

Iterator của set/map hỗ trợ đi từng bước, nên không dùng được it + k. Hàm next(it, k) có thể đi qua k phần tử và tốn O(k). Set/map thường được cài bằng cây tìm kiếm cân bằng, nhờ đó các hàm thành viên tìm kiếm trong O(log n). Chuẩn C++ không bắt buộc dùng một loại cây cụ thể.

Hãy gọi s.lower_bound(x) và s.upper_bound(x). Các hàm chung như std::lower_bound(s.begin(), s.end(), x) có thể phải di chuyển iterator tuyến tính dù số phép so sánh là logarithm.

Cách chia chủ đề tham khảo bài STL — Associative containers và Unordered containers của 2School Guideline. Các giải thích và ví dụ trên được viết lại cho lộ trình map/set này. Quy tắc thao tác được đối chiếu với bản thảo chuẩn C++ về associative containers và truy cập map.

Bài 2. LeetCode - Valid Anagram

Tóm tắt

  • Cho hai chuỗi chữ cái tiếng Anh thường \(s,t\). Kiểm tra có thể hoán vị các ký tự của \(s\) để được \(t\) hay không. Độ dài mỗi chuỗi không quá \(5\cdot10^4\).
  • Hai tham số của hàm là chuỗi s và t. Trả về giá trị boolean.

Input

s = "anagram", t = "nagaram"

Output

true

Giải thích

anagram và nagaram trả true. rat và car trả false.

Lời giải
  1. Dùng map<char,int> lưu chênh lệch tần suất. Mỗi ký tự trong \(s\) cộng một, mỗi ký tự trong \(t\) trừ một. Hai chuỗi hợp lệ khi mọi chênh lệch đều bằng không.
  2. Nếu độ dài khác nhau, trả false. Đếm tăng theo \(s\), đếm giảm theo \(t\), rồi duyệt map để kiểm tra.
  3. Hoán vị giữ nguyên số lượng từng ký tự. Ngược lại, khi hai chuỗi có cùng số lượng của mọi ký tự, có thể sắp xếp lại các ký tự của chuỗi này để tạo chuỗi kia. Chênh lệch bằng không kiểm tra đúng điều kiện đó.

Code mẫu

C++17
1234567891011121314151617181920212223
class Solution {
public:
    bool isAnagram(string s, string t) {
        if (s.size() != t.size()) {
            return false;
        }

        map<char, int> difference;
        for (char c : s) {
            ++difference[c];
        }
        for (char c : t) {
            --difference[c];
        }

        for (const auto& entry : difference) {
            if (entry.second != 0) {
                return false;
            }
        }
        return true;
    }
};

Độ phức tạp

Với \(n=|s|+|t|\) và \(\sigma\) là số ký tự khác nhau, thời gian \(O(n\log(\sigma+1))\), bộ nhớ \(O(\sigma)\). Trong đề này \(\sigma\le26\) nên thời gian là \(O(n)\).

Lưu ý

Set chỉ lưu ký tự nào đã xuất hiện. Bài này cần biết cả số lần xuất hiện nên dùng map đếm tần suất. Với bảng chữ cái cố định, mảng 26 phần tử cũng giải được bài.

Bài 3. LeetCode - Intersection of Two Arrays

Tóm tắt

  • Cho hai mảng số nguyên. Trả về những giá trị xuất hiện trong cả hai mảng, mỗi giá trị chỉ xuất hiện một lần trong kết quả. Thứ tự kết quả tùy ý. Mỗi mảng có tối đa \(1000\) phần tử.
  • Hai tham số là mảng nums1 và nums2. Trả về mảng chứa các giá trị chung phân biệt, theo thứ tự tùy ý.

Input

nums1 = [1, 2, 2, 1]
nums2 = [2, 2]

Output

[2]

Giải thích

\([1,2,2,1]\) và \([2,2]\) cho kết quả \([2]\).

Lời giải
  1. Đưa các giá trị của mảng thứ nhất vào set. Duyệt mảng thứ hai, nếu tìm thấy giá trị trong set thì thêm vào kết quả và xóa giá trị đó khỏi set.
  2. Tạo set từ nums1. Với mỗi x trong nums2, dùng find(x). Nếu tồn tại thì lưu x, sau đó gọi erase(it).
  3. Một giá trị chỉ được thêm vào kết quả khi có trong cả hai mảng. Ngay sau lần thêm đầu tiên, giá trị được xóa khỏi set nên các lần gặp tiếp theo không thể thêm lại. Mọi giá trị chung đều được tìm thấy ở lần xuất hiện đầu tiên trong mảng thứ hai.

Code mẫu

C++17
123456789101112131415161718
class Solution {
public:
    vector<int> intersection(vector<int>& nums1,
                             vector<int>& nums2) {
        set<int> available(nums1.begin(), nums1.end());
        vector<int> answer;

        for (int x : nums2) {
            auto it = available.find(x);
            if (it != available.end()) {
                answer.push_back(x);
                available.erase(it);
            }
        }

        return answer;
    }
};

Độ phức tạp

Với hai độ dài \(n,m\), thời gian \(O((n+m)\log(n+1))\), bộ nhớ phụ \(O(n)\), chưa tính mảng kết quả.

Lưu ý

Bài yêu cầu giá trị phân biệt. Nếu đề đổi thành lấy cả số lần lặp trong giao hai mảng, cần quản lý tần suất bằng map hoặc dùng multiset.

Bài 4. CSES - Sum of Two Values

Tóm tắt

  • Cho mảng \(n\) số và mục tiêu \(x\). Tìm hai vị trí khác nhau có tổng bằng \(x\). In hai chỉ số bắt đầu từ \(1\), hoặc IMPOSSIBLE. \(n\le2\cdot10^5\).
  • Dòng đầu chứa \(n,x\). Dòng tiếp theo chứa \(n\) phần tử. In hai chỉ số bắt đầu từ \(1\), hoặc IMPOSSIBLE.

Input

4 8
2 7 5 1

Output

2 4

Giải thích

Với \([2,7,5,1]\), \(x=8\), có thể in \(2\,4\) vì \(7+1=8\).

Lời giải
  1. Khi đang xét \(a_i\), cần tìm giá trị \(x-a_i\) trong những phần tử đã duyệt. Dùng map lưu giá trị và một vị trí đã gặp của nó.
  2. Tìm phần bù trước. Nếu tồn tại thì in vị trí đã lưu và \(i\). Nếu chưa có, mới lưu position[a[i]] = i.
  3. Map chỉ chứa các vị trí nhỏ hơn \(i\), nên hai vị trí luôn khác nhau. Nếu một cặp hợp lệ tồn tại, khi duyệt tới vị trí phía sau, giá trị tại vị trí phía trước đã có trong map và sẽ được tìm ra.

int main() {

Bài 5. CSES - Concert Tickets

Tóm tắt

  • Có \(n\) vé với giá cho trước. Lần lượt \(m\) khách đến, mỗi khách có ngân sách \(t\). Bán cho khách vé đắt nhất có giá \(\le t\), rồi xóa vé đó. Nếu không có vé phù hợp, in \(-1\). \(n,m\le2\cdot10^5\).
  • Dòng đầu chứa \(n,m\). Dòng thứ hai chứa \(n\) giá vé. Dòng thứ ba chứa ngân sách của \(m\) khách. In một kết quả cho mỗi khách.

Input

5 3 7 8 5
4 8 3

Output

8
-1

Giải thích

Vé \([5,3,7,8,5]\), khách \([4,8,3]\) cho kết quả lần lượt \(3,8,-1\).

Lời giải
  1. Dùng multiset để lưu các vé còn lại, kể cả vé trùng giá. upper_bound(t) trỏ đến giá đầu tiên \(>t\), nên phần tử ngay trước nó là giá lớn nhất \(\le t\).
  2. Tìm it = tickets.upper_bound(t). Nếu it == begin(), không có vé phù hợp. Ngược lại giảm iterator, in giá và xóa đúng vé đó bằng erase(it).
  3. Multiset luôn chứa đúng các vé chưa bán. Theo thứ tự tăng dần, phần tử đứng trước giá đầu tiên vượt ngân sách chính là vé đắt nhất khách mua được. Xóa một iterator giữ lại những vé khác cùng giá cho khách sau.

Code mẫu

C++17
123456789101112131415161718192021222324252627282930
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    cin >> n >> m;

    for (int i = 0; i < n; ++i) {
        int price;

        }

Bài 6. CSES - Playlist

Tóm tắt

  • Cho dãy \(n\) mã bài hát, tìm độ dài đoạn liên tiếp dài nhất không chứa mã trùng nhau. \(n\le2\cdot10^5\).
  • Dòng đầu chứa \(n\). Dòng tiếp theo chứa \(n\) mã bài hát. In độ dài đoạn hợp lệ dài nhất.

Input

8
1 2 1 3 2 7 4 2

Output

5

Giải thích

Dãy \([1,2,1,3,2,7,4,2]\) có đoạn \([1,3,2,7,4]\) dài \(5\).

Lời giải
  1. Duy trì đoạn hợp lệ \([left,right]\). Map lưu vị trí xuất hiện gần nhất của mỗi mã. Khi mã hiện tại từng xuất hiện tại \(p\), đặt \(left=\max(left,p+1)\) để bỏ lần xuất hiện cũ nếu còn nằm trong đoạn.
  2. Với từng \(right\), tìm vị trí cũ rồi cập nhật \(left\). Lưu vị trí mới và cập nhật đáp án bằng \(right-left+1\).
  3. Trước khi thêm phần tử mới, đoạn hiện tại không trùng. Chỉ mã mới thêm có thể gây trùng. Bỏ mọi vị trí đến lần xuất hiện gần nhất của nó sẽ loại đúng sự trùng đó. Cận trái được giữ nhỏ nhất có thể mà đoạn vẫn hợp lệ, nên ta xét đoạn hợp lệ dài nhất kết thúc tại mỗi \(right\).

Code mẫu

C++17
12345678910111213141516171819202122232425262728
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    map<int, int> lastPosition;
    int left = 1;
    int answer = 0;

    for (int right = 1; right <= n; ++right) {
        int song;
        cin >> song;
        auto it = lastPosition.find(song);
        if (it != lastPosition.end()) {
            left = max(left, it->second + 1);
        }

        lastPosition[song] = right;
        answer = max(answer, right - left + 1);
    }

    cout << answer << '\n';
    return 0;
}

Độ phức tạp

\(O(n\log n)\) thời gian, \(O(n)\) bộ nhớ phụ.

Lưu ý

Thiếu max có thể khiến cận trái lùi về trước. Với \([1,2,2,1]\), khi xét số \(1\) cuối cùng, lần xuất hiện cũ đã nằm ngoài đoạn và không được kéo \(left\) lùi lại.

Bài 7. CSES - Subarray Sums II

Tóm tắt

  • Cho mảng \(n\) số nguyên, có thể có số âm. Đếm số đoạn liên tiếp không rỗng có tổng bằng \(x\). \(n\le2\cdot10^5\), \(|a_i|,|x|\le10^9\).
  • Dòng đầu chứa \(n,x\). Dòng tiếp theo chứa \(n\) số nguyên. In số đoạn liên tiếp không rỗng có tổng bằng \(x\).

2 -1 3 5 -2

Output

2

Giải thích

Với \([2,-1,3,5,-2]\), \(x=7\), hai đoạn hợp lệ là \([-1,3,5]\) và \([3,5,-2]\).

Lời giải
  1. Gọi \(P_i=a_1+\cdots+a_i\), \(P_0=0\). Tổng đoạn \([l,r]\) bằng \(x\) khi \(P_r-P_{l-1}=x\), tức \(P_{l-1}=P_r-x\). Với mỗi tổng tiền tố hiện tại, cần biết có bao nhiêu tổng tiền tố trước đó bằng nó trừ \(x\).
  2. Đặt frequency[0] = 1. Với từng phần tử, cập nhật tổng tiền tố \(P\). Cộng số lần đã gặp giá trị \(P-x\) vào đáp án, rồi tăng tần suất của \(P\).
  3. Trước khi xử lý vị trí \(r\), map đếm đúng \(P_0,\ldots,P_{r-1}\). Mỗi lần xuất hiện của \(P_r-x\) tương ứng duy nhất với một đầu trái hợp lệ. Mỗi đoạn được đếm đúng một lần khi duyệt đến đầu phải của nó.

Code mẫu

C++17

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    long long target;
    cin >> n >> target;
    map<long long, long long> frequency;
    frequency[0] = 1;
    long long prefix = 0;
    long long answer = 0;

    for (int i = 0; i < n; ++i) {
        long long value;
        cin >> value;
        prefix += value;
        auto it = frequency.find(prefix - target);
        if (it != frequency.end()) {
            answer += it->second;
        }
        ++frequency[prefix];
    }

    cout << answer << '\n';
    return 0;
}

Độ phức tạp

\(O(n\log n)\) thời gian, \(O(n)\) bộ nhớ phụ.

Lưu ý

Quên \(P_0=0\) sẽ bỏ sót các đoạn bắt đầu từ phần tử đầu tiên. Tăng tần suất trước khi đếm có thể đếm cả đoạn rỗng khi \(x=0\). Tổng tiền tố và đáp án phải dùng long long.

Bài 8. CSES - Traffic Lights

Tóm tắt

  • Con đường từ \(0\) đến \(x\) ban đầu chưa có đèn. Thêm \(n\) đèn tại những vị trí phân biệt nằm trong đường. Sau mỗi lần thêm, in độ dài khoảng không có đèn dài nhất. \(n\le2\cdot10^5\), \(x\le10^9\).
  • Dòng đầu chứa độ dài đường \(x\) và số đèn \(n\). Dòng tiếp theo chứa \(n\) vị trí theo thứ tự thêm. In \(n\) độ dài lớn nhất tương ứng.

Input

8 3
3 6 2

Output

5 3 3

Giải thích

\(x=8\), thêm đèn tại \(3,6,2\) thì kết quả lần lượt là \(5,3,3\).

Lời giải
  1. Set lưu các vị trí, ban đầu gồm \(0,x\). Multiset lưu độ dài khoảng trống, ban đầu có \(x\). Khi thêm \(p\), tìm hai vị trí kề \(L<p<R\) bằng upper_bound. Xóa một độ dài \(R-L\), thêm \(p-L\) và \(R-p\), rồi thêm \(p\) vào set. Giá trị lớn nhất trong multiset là đáp án.
  2. Mỗi đèn mới chỉ chia khoảng chứa nó thành hai khoảng. Các khoảng khác được giữ nguyên. Cập nhật trên duy trì đúng tập các độ dài hiện tại, bao gồm những độ dài bằng nhau, nên phần tử lớn nhất chính là khoảng dài nhất.

Code mẫu

C++17
1234567891011121314151617181920212223242526272829303132
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int roadLength, n;
    cin >> roadLength >> n;
    set<int> positions = {0, roadLength};
    multiset<int> gaps = {roadLength};

    for (int i = 0; i < n; ++i) {
        int p;
        cin >> p;
        auto rightIt = positions.upper_bound(p);
        auto leftIt = prev(rightIt);
        int left = *leftIt;
        int right = *rightIt;

        auto oldGap = gaps.find(right - left);
        gaps.erase(oldGap);
        gaps.insert(p - left);
        gaps.insert(right - p);
        positions.insert(p);

        if (i > 0) cout << ' ';
        cout << *gaps.rbegin();
    }
    cout << '\n';
    return 0;
}

Độ phức tạp

\(O(n\log n)\) thời gian và \(O(n)\) bộ nhớ phụ.

Lưu ý

Phải xóa đúng một khoảng bằng iterator vì nhiều khoảng có thể cùng độ dài. Hai mốc \(0,x\) bảo đảm luôn có hàng xóm hai phía. Code dựa vào điều kiện đề bảo đảm các vị trí thêm vào phân biệt và nằm trong \((0,x)\).

Thứ tự độ khó là gợi ý cho việc học. Đề gốc được liên kết ở tên từng bài.
